Catalogs Used in TROVE
======================

The table below lists all of the tables we use in TROVE for associating targets with 
galaxies, (variable) stars (i.e., point sources), and/or AGN. This table will be more 
up to date than that presented in Franz et al., in prep as our catalogs in use 
evolve with time.
