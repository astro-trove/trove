Row and badge markers
Yellow row
{% if is_kilonova %} KilonovaSCORER ran on this candidate but could not produce a score. The score shown is TROVE's photometry factor instead, so the candidate stays rankable rather than being dropped or zeroed. Hover the row to see the reason. Common causes: no detections inside the grid's 0–30 day window, no usable distance, no observation in a bandpass the simulation grid models, or a failure inside the scorer itself. {% else %} One or more of TROVE's photometry checks had no data to run on, so the factor shown rests on partial evidence. Hover the row to see which are missing. The score is deliberately not penalised for this: it is the product of the checks that did run, so a missing measurement leaves it unchanged. That is why a candidate with no photometry at all can still show a factor of 1 — nothing was tested, so nothing lowered it. The highlight marks the difference between “passed every check” and “was never checked”, which the number alone cannot show. {% endif %}
